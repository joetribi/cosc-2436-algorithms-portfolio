# COSC 2436 - Algorithms Portfolio

A semester-long collection of 12 chapter labs covering data structures and algorithms in Python. Each chapter folder contains the working program files plus a written lab report.

## Author

Alexander Sjogreen - COSC 2436, Summer 2026

## Description

This portfolio contains my work from Chapters 1–12 of COSC 2436. The labs cover searching, sorting, recursion, hash tables, graphs, trees, shortest-path algorithms, greedy algorithms, dynamic programming, and k-nearest neighbors. The goal of this portfolio is to demonstrate my understanding and application of fundamental data structures and algorithms throughout the semester.

## How to Run a Lab

Each lab is a standalone Python program. Navigate into the chapter folder and run the main file:

cd CH01
python3 main.py

## Requirements

- Python 3.10 or newer
- CH01 additionally requires matplotlib for its growth chart:
  `pip install matplotlib`
- All other chapters use only the Python standard library.
